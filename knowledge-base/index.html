      Stage 1: End-to-End Machine Learning

      The primary goal is to learn the complete modeling process, with secondary goals of understanding common machine learning algorithms (their advantages, disadvantages, principles, steps, applications) and learning modeling tools (Sklearn \ scikit-learn), in order to quickly become familiar with end-to-end modeling.

      Practice with multiple cases to become familiar with the end-to-end modeling process. Main topics include:

      1. Understand related concepts such as Artificial Intelligence, Machine Learning, Deep Learning, and Statistical Machine Learning;
      2. Learn the principles of common algorithms. Focus on understanding their advantages, disadvantages, principles, steps, and applications without delving too deeply into mathematical formulas;
      3. Learn the step-by-step modeling process, e.g., CRISP-DM;
      4. Learn modeling tools, e.g., scikit-learn;
      5. Practice on small datasets, e.g., the UC Irvine Machine Learning Repository;
      6. Deploy serialized or packaged models as a Flask API or Streamlit\Gradio application;

      Supplementary Content:

      1. Learn about Automated Machine Learning (AutoML) tools.
      2. Learn about Python libraries for handling large datasets.

      Recommended Reading:

      • Deep Learning: From Basics to Practice (Volume 1) - [US] Andrew Glassner
      • Machine Learning with Python Cookbook - Chris Albon
      • Machine Learning Mastery with Python - Jason Brownlee
      • Sklearn Tutorials (by Caicai)
      • Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow - (FR) Aurélien Géron
      • Python Machine Learning - (US) Sebastian Raschka, (US) Vahid Mirjalili
